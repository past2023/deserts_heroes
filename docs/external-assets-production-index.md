## Shared mandatory rules

```text
Format: PNG
Color space: sRGB
Direction: right-facing source art
Filtering: no anti-aliasing for pixel art
Transparency: valid RGBA/indexed alpha
Naming: lowercase snake case
Text: never baked into world art
Temporary FX: generated by the engine, not baked into PNGs
```

Before producing a full animation set, deliver one idle frame for scale/pivot approval. After approval, produce one complete movement or attack sheet and verify it in-game before finishing every damage/death state. This staged process prevents expensive rework.
