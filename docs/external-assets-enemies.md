# External Asset Production — Infantry Enemies and Combat NPCs

## Purpose

This document defines the external PNG contract for all non-vehicle enemies in **Desert's Heroes**. Helicopters, tanks, the gunship and final fortress belong to `external-assets-vehicles.md`.

Current infantry types:

- rifle soldier;
- grenadier;
- knife/melee attacker;
- elite bazooka soldier;
- sandbag turret gunner.

All currently use generated prototype sprites. The dimensions below are the final recommended target for direct PNG replacement.

# 1. Global enemy scale

```text
Logical viewport: 960 × 540
Ground baseline: Y 470
Player frame: 100 × 100
Enemy frame: normally 100 × 100
Direction: every source enemy faces RIGHT
Pivot: bottom-center (50,100)
Current gameplay hitbox: 24 × 54
```

Use the same 100×100 cell as the playable characters so weapons, cover, platforms and melee range remain readable. Character body width may vary visually, but preserve the 24×54 gameplay hitbox unless a specific enemy is intentionally larger.

## Universal technical rules

- Transparent RGBA or indexed PNG with valid transparency.
- No anti-aliasing.
- Normally alpha 0 or 255.
- No white matte around transparent edges.
- Identical frame canvas for every state of one enemy.
- Feet remain bottom-center.
- Every source frame faces right; engine mirrors left.
- No muzzle flashes, bullets, shells, grenades, explosions, blood, smoke, shadows, score text or hit rings baked into the PNG.
- Internal FX and audio are generated by the engine.
- Keep important weapon sockets stable through recoil.

# 2. Shared animation vocabulary

Use these state names whenever they apply:

```text
idle
move
attack
hit
damage
death
```

State priority in the future renderer:

```text
death > hit > attack > damage > move > idle
```

Recommended playback:

| State | Typical FPS | Loop? |
|---|---:|---|
| Idle | 3–5 | yes |
| Move/run | 10–12 | yes |
| Fire/attack | 12–16 | usually once or sustained while firing |
| Hit | 16 | once |
| Damage idle | 4–8 | yes |
| Death | 10–12 | once |

# 3. Rifle soldier

## Gameplay behavior

- Patrols near spawn point.
- Advances when far from the player.
- Stops at firing distance.
- Fires three-round bursts.
- Dies from one normal hit.

## Canvas and hitbox

```text
Frame canvas: 100 × 100
Pivot: (50,100)
Hitbox: 24 × 54
Suggested rifle muzzle: (96,52)
```

## Required files

| File | Frames | Sheet size | FPS |
|---|---:|---:|---:|
| `enemy_rifle_idle.png` | 4 | 400×100 | 4 loop |
| `enemy_rifle_run.png` | 6 | 600×100 | 10 loop |
| `enemy_rifle_fire.png` | 5 | 500×100 | 14 once/burst |
| `enemy_rifle_hit.png` | 2 | 200×100 | 16 once |
| `enemy_rifle_death.png` | 8 | 800×100 | 12 once |

Fire sequence recommendation:

```text
Frame 0: aim/anticipation
Frame 1: recoil peak and bullet event
Frames 2–4: settle and recover
```

Only commission a state after gameplay code has a real event for it.

# 9. Enemy sockets and events

Every delivery should include a socket/event note table:

```text
state: fire
muzzle: x,y
projectile event frame: N
recoil peak frame: N
active melee frame range: N–N
grenade release frame: N
```

Coordinates are absolute inside the right-facing frame canvas. Runtime conversion subtracts the pivot and mirrors X when facing left.

# 10. Hit and death presentation

The engine supplies:

- white hit silhouette;
- weapon-colored impact burst;
- concentric hit rings;
- sparks and armor fragments;
- hit-stop;
- camera shake;
- blood/energy particles where appropriate;
- score and combo text;
- death sound.

Enemy death sheets should therefore show body mechanics only:

- loss of balance;
- armor/body deformation;
- fall or collapse;
- weapon separation if desired;
- a stable final pose or launch-ready body frame.

Do not fill the death sheet with large opaque explosions that hide collision feedback.

# 11. Original faction design

Use an original retro-future desert/space military identity.

Recommended visual families:

| Enemy | Suggested visual identity |
|---|---|
| Rifle soldier | sand/olive pressure suit with red optical sensor |
| Grenadier | yellow hazard markings and grenade harness |
| Melee attacker | light armor, exposed mobility joints, short energy blade |
| Bazooka elite | dark oxide/crimson armor and oversized shoulder weapon |
| Turret gunner | reinforced helmet, heavy gloves, magenta weapon-energy accents |

Avoid copying Metal Slug uniforms, insignia, helmets, facial features or exact silhouettes. The target is expressive arcade animation quality, not replicated art.

# 12. Palette and lighting

Suggested color limits:

```text
Standard infantry: 20–32 colors
Elite/bazooka: 24–40 colors
Turret gunner: 24–40 colors
```

Use:

- one near-black outline ramp;
- 3–5 body-material shades;
- warmer upper-left highlights;
- cooler underside shadows;
- a small high-saturation faction accent;
- controlled sand/rust wear near boots and equipment.

Do not distribute random one-pixel noise evenly across suits. Cluster detail around armor edges, joints, straps and weapons.

# 13. Sheet and file organization

```text
assets/
  enemies/
    rifle/
      enemy_rifle_idle.png
      enemy_rifle_run.png
      enemy_rifle_fire.png
      enemy_rifle_hit.png
      enemy_rifle_death.png
    grenadier/
    melee/
    bazooka/
    turret/
```

Horizontal sheets are read left-to-right. Multi-row sheets, if required later, are read left-to-right and then top-to-bottom. Keep sheet dimensions below 4096 px where practical.

# 14. Delivery package

Include `enemy-notes.md` containing:

- frame canvas dimensions;
- pivot;
- final hitbox recommendation;
- FPS;
- event/release frame;
- muzzle/melee socket;
- recoil peak;
- whether mirroring is allowed;
- any intentional semi-transparent pixels.

# 15. QA checklist

- [ ] Exact frame size and sheet grid.
- [ ] Source faces right.
- [ ] Feet remain bottom-center.
- [ ] Body does not jitter between idle/run/fire.
- [ ] Weapon socket stays aligned through recoil.
- [ ] Attack event frame is documented.
- [ ] Hitbox excludes long weapon barrels.
- [ ] No baked internal FX or localized text.
- [ ] Alpha edges contain no white matte.
- [ ] Loop returns to frame 0 without a position jump.
- [ ] Enemy is distinguishable from player characters at silhouette level.
- [ ] Palette remains readable against sky, mountain and dune layers.
- [ ] Design and insignia are original to Desert's Heroes.
